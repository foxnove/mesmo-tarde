# Diego Fox — Mesmo Tarde 🎵
### Caderno Oficial de Cifras e Letras (Estilo Cifra Club)

Página web responsiva com as cifras e letras de todas as 12 faixas do álbum **Mesmo Tarde** do artista **Diego Fox**.

---

## 📱 Recursos da Versão Web (Mobile & Desktop)
- 🎸 **Transposição de Tom em Tempo Real** (♭ -1 / ♯ +1).
- 📜 **Auto-Rolagem Automática** com velocidades ajustáveis (1x, 2x, 3x).
- 🔠 **Ajuste do Tamanho da Fonte** (A- / A+).
- 🌙 **Modo Escuro / Claro** (Dark Mode) para leitura no palco ou à noite.
- 📄 **Download dos PDFs** com cada música formatada em **exatamente 1 página A4**.

## 🌐 Como Ativar o GitHub Pages
1. Vá em **Settings** > **Pages** no repositório.
2. Em **Branch**, selecione main e a pasta /(root).
3. Clique em **Save**.
4. Em instantes o site estará acessível em:
